# Порядок KPI-карточек Метрики

## Резюме

Порядок сводных карточек на вкладке Метрики больше не зашит в `buildMetrikaSection()`. Набор и порядок задаёт конфиг `summary_metrics`, по умолчанию как раньше: визиты, просмотры, уникальные посетители, отказы. Неизвестные ключи игнорируются. Булевы `widgets.*` по-прежнему включают остальные блоки (график, таблицы, Вебмастер) и могут скрыть парную карточку. Приложение может переопределить `protected buildSummaryMetrics()` в наследнике страницы. CSV и вкладка Вебмастера не менялись.

## План

1. Добавить `summary_metrics` в конфиг пакета с текущим порядком (без ломки BC).
2. Вынести сбор карточек в `buildSummaryMetrics()`.
3. Тесты: дефолтный порядок, свой порядок, неизвестный ключ, скрытие через `widgets`.
4. Обновить README (EN/RU) и changelog.
5. PR → зелёный CI → squash в `main` → релиз `v1.3.0`.
